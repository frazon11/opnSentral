# Managed WireGuard

The Managed WireGuard page identifies reciprocal peers between managed OPNsense systems.

Available functions include:

- enable or disable both sides of a managed pair
- display partial configuration states
- create a dedicated experimental site-to-site tunnel
- create automatic pre-change backups
- create firewall rules in category `WireGuard`
- mark generated rules with `managed by opnCentral [WG-xxxxxx]`

Confirm all interface keys, networks, public endpoints and ports before using the tunnel wizard.
